## Run it

`python3 main.py` copies `entry.png` to `$MAKEFUN_OUTPUT_DIR` (or `/output`). The image is a 1024×1024 PNG of 221,199 bytes; the copy is byte-for-byte, so repeated runs write identical bytes.
